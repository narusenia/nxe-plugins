## 一言で

**構造はスイス、信号だけが光る。**

グリッド・罫線・1 アクセント・角の無い面で組み、その上で**動いている信号**
（スペクトル、伝達曲線、メーター）だけに光と曲線を許す。静止している要素に
光を使うと装飾になる。

## v0 の規則から変えるもの

| 規則 | v2 | 理由 |
|---|---|---|
| 1 窓 1 アクセント、5 本は OKLCH の明度・彩度をそろえた家族 | 維持 | シリーズ性の核 |
| グリッドと罫線が構造。窓幅は共通の 1 定数、高さは部品の合計 | 維持 | 同上 |
| 影なし、角丸ゼロ | 維持 | 解くとスイスでなくなる。リッチさは光と動きで出す |
| 記号は直線だけ | 維持 | 記号の規則は v0 の `UI-17` のまま |
| 1 書体 1 ウェイト | **ウェイト 2 段**（Regular / Medium）。意味をウェイトに持たせない規則は残す | vizia では出せなかった段を回収する |
| letter-spacing は無い（vizia が持たない） | **使う。** 眉（region の名前）とラベルの大文字に | トラッキングはスイスの組版の主な道具 |
| 塗りは全部フラット（`UI-21`） | 量を表す塗りはフラットのまま。**光（グロー・ブルーム）は動いている信号にだけ** | — |
| 曲線を描かない | **信号だけ曲線可**（単調三次補間）。記号とレイアウトは直線のまま | — |
| 反転面は 2 つまで | 維持。型ごとに使い方が変わる（下） | — |

## シリーズと強度

部品・グリッド・書体・罫線・窓幅は全シリーズで共有する。シリーズで変えるのは
**色の家族**と**光・動きの量**だけ。

| シリーズ | 対象 | 強度 | 型 |
|---|---|---|---|
| Mix 系（Basic） | v2 の 6 本（Doubler / Velour / Sparkleur / Air / Diorama / Pumice） | 信号だけが光る | **H4 左版**（決定） |
| Colour | 音に色を足すもの（今後） | 地は無彩色。色はデータ（和音の音ごと）にだけ乗る | **丸い面の 2 段**（決定、下） |
| Design | 音を作り変えるもの（今後） | 大きな可視化が主役。動きを許す | **正方形の図 + 段組 + 寄生先**、精密か攻撃的かで 2 種（決定、下） |
| Create | 音源（今後） | 舞台（全発振器の可視化）が主役 | **舞台 + 鍵盤** か **H4 + 舞台**（決定、下） |
| Kit | 1 機能の小さなプラグイン（今後） | 差し色がシリーズを表す | **カードの下に L**（決定、下） |

ラインナップと順番は [`../implementation/series-plan.md`](../implementation/series-plan.md)。
今後のシリーズの案は別のキャンバスにある（非公開、所有者のみ閲覧可、★が採用）:
<https://claude.ai/artifact/EG3dQcPkPPwSGbQY5DZ29J>

### 今後のシリーズの型

まだ実装していない。寸法は最初の 1 本で決める。

- **Colour（キャンバスの Colour 6）** — 左に操作部の面、右に和音の帯と図の面。
  面はどれも角を丸める。**角丸ゼロの規則の、唯一の例外**で、Colour だけが持つ
  柔らかさとして使う。面は無彩色で、色は和音の音ごとのチップと倍音にだけ乗る
- **Design** — 左に正方形の図（元の音と、作り変えた音を重ねる）、右に 3 列の
  段組（入力 / 加工 / 出力）と、何で何を動かすかの一覧。2 種を使い分ける
  - **製図（Design 7）** — 黒地、細いスライダー、アシッドグリーン。
    細かく狙う精密な系統（Parasite、Singularity、Topology）
  - **反転（Design 8）** — 明るい地、黒い図、オレンジ。音を壊す攻撃的な系統
    （Devour、Dislocate）
- **Create** — 2 種を使い分ける
  - **舞台 + 鍵盤（Create 6）** — 上に舞台、中にノブ 1 列、下に鍵盤。
    鍵盤で弾くことが中心の楽器（Iridesce）
  - **H4 + 舞台（Create 7）** — Mix 系のサイドバーの右に舞台、隅に位相の円。
    パラメーターが多く、音色を作り込む楽器（Swarm、Rhizome）
- **Kit（Kit 7）** — 上に図を大きく、差し色の L を左と下に回し、下の帯に
  つまみを置く。11 本とも同じ型で、差し色がどのシリーズの Kit かを表す

どのプラグインがどちらの型かは仮の割り当てで、最初に作るときに決め直してよい。

## Mix 系の型 — H4 左版

```
┌───────────┬──────────────────────────────┐
│ SIDEBAR   │ FIGURE（主図）                │
│ (accent)  │ (accent の地に暗い塗りの波形)  │
│ wordmark  │                              │
│ 主題の数字 ├──────────────────────────────┤
│ 目盛り    │ 下の列（帯域・ボイスなど）     │
│ マクロ    │ （暗い地、罫線で区切る）       │
│ NXE       │                              │
└───────────┴──────────────────────────────┘
```

- **サイドバーと主図は 1 つの L 字の反転面**として地続きにする
- v0 のステータスバー（ポインタが乗っているものの説明）は H4 の案に描いていない。
  残すか、どこに置くか、反転面にするかは `V2-9` で決める。反転面にするなら、
  L 字と合わせて 2 つで上限になる
- サイドバーは上から順に: ワードマーク、主題の数字（窓で一番大きい字、
  1 つだけ）、その数字の目盛り、マクロの 2 列、`NXE` の印
- **主図の面は共通、描くものはプラグインごと**。面はアクセントの地で、その上の
  図は**暗い塗り＋白い線**で描く（B 案の差し色）。Sparkleur ならスペクトルの波形、
  Diorama なら `REQ-DIO-013` の距離の図（直接音と反射）、というように、各
  プラグインの UI 仕様が要求する図を入れる。線はゆっくり明滅してよい（点滅は不可）
- 主図の縦の区切り線は、下の列の境界にそろえる
- **下の列もプラグインごと**。帯域を持つもの（Sparkleur など）は v0 の帯域列
  （眉 → バー → 読み値 → SOLO）を引き継ぐ。Doubler はボイスを並べ、UI 仕様が
  外しているボイスの SOLO は置かない。何を並べるかは各プラグインの
  `specifications/ui.md` が正

### 寸法（`V2-9` で確定）

数字はすべて `nxe-egui` の定数（`theme.rs` ほか）が正で、ここはその要約。
**実機で見て動かすことはある**（`ui.md` の「Dimensions are only settled in a
host」）。動かしたら両方を直す。

| 部分 | 寸法 |
|---|---|
| 窓の幅 | 880（`WINDOW_WIDTH`）。高さはプラグインごとに足し算で出す |
| サイドバー | 幅 220、左右の余白 16。上から ワードマーク 18 / 主題の眉 9 / 主題 40 / 目盛り 12、下に `NXE` の印（`sidebar::HEAD` / `FOOT`） |
| マクロのつまみ | 径 40、名前と値を入れて 56 × 70。**1 段に 2 つなら間 16、3 つなら間 8**。段の間 12 |
| 上の帯 | 高さ 24。プリセット欄が残りの幅を取り、右に切り替え（`segment`、高さ 20）を並べる。間 8 |
| 主図 | 右の列の残り全部。**サイドバーの下端と主図の下の列の下端をそろえる**ので、高さはサイドバーから決まる。200 を切ったら段を減らす |
| 下の列 | 上に 12 空けてタブ（高さ 20）、8 空けて本体、下に 12。左右の余白 12。メーター（IN L/R・OUT L/R、幅 56）は右端に常に置く |
| 表の行 | 眉 14、行 16（Doubler の 8 声）または 24（Sparkleur の 4 行） |

書体の段: 眉 9（字間 1.2、大文字）、値 10（Geist Mono）、名前 12、読み値 13、
ワードマーク 18（Inter Medium）、主題 40（Geist Mono）。

**ステータスバーは置かない**（`V2-9` で決めた）。v0 では何に触れているかを
説明していたが、v2 の窓は操作子が全部自分の名前を持ち、主図の帯や点にも名前が
付いている。1 行のために主図を 20 px 削るより、図を大きくするほうを取った。

## 書体

Mix 系は **Inter（Regular / Medium）+ letter-spacing**、数字は **Geist Mono**。
Host Grotesk（G 案で試した）と allo は候補として残す。替えるなら、プラグインの
バイナリに埋め込めるライセンスかを先に確かめる。
