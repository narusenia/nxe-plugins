## 一言で

**構造はスイス、信号だけが光る。**

グリッド・罫線・1 アクセント・角の無い面で組み、その上で**動いている信号**
（スペクトル、伝達曲線、メーター）だけに光と曲線を許す。静止している要素に
光を使うと装飾になる。

## v0 の規則から変えるもの

| 規則 | v2 | 理由 |
|---|---|---|
| 1 窓 1 アクセント、5 本は OKLCH の明度・彩度をそろえた家族 | 維持 | シリーズ性の核 |
| グリッドと罫線が構造。窓幅は共通の 1 定数、高さは部品の合計 | 維持 | 同上 |
| 影なし、角丸ゼロ | 維持 | 解くとスイスでなくなる。リッチさは光と動きで出す |
| 記号は直線だけ | 維持 | 記号の規則は v0 の `UI-17` のまま |
| 1 書体 1 ウェイト | **ウェイト 2 段**（Regular / Medium）。意味をウェイトに持たせない規則は残す | vizia では出せなかった段を回収する |
| letter-spacing は無い（vizia が持たない） | **使う。** 眉（region の名前）とラベルの大文字に | トラッキングはスイスの組版の主な道具 |
| 塗りは全部フラット（`UI-21`） | 量を表す塗りはフラットのまま。**光（グロー・ブルーム）は動いている信号にだけ** | — |
| 曲線を描かない | **信号だけ曲線可**（単調三次補間）。記号とレイアウトは直線のまま | — |
| 反転面は 2 つまで | 維持。型ごとに使い方が変わる（下） | — |

## シリーズと強度

部品・グリッド・書体・罫線・窓幅は全シリーズで共有する。シリーズで変えるのは
**色の家族**と**光・動きの量**だけ。

| シリーズ | 対象 | 強度 | 型の候補 |
|---|---|---|---|
| Mix 系 | 既存 5 本（Doubler / Velour / Sparkleur / Air / Diorama） | 信号だけが光る | **H4 左版**（決定） |
| Colour | カラーベース向け（今後） | 地にも色が乗る。グロー・ブルームを広く許す | H1 系（未決） |
| Design | ベースの音作り（今後） | 大きな可視化が主役。動きを許す | G 系（未決） |

## Mix 系の型 — H4 左版

```
┌───────────┬──────────────────────────────┐
│ SIDEBAR   │ FIGURE（主図）                │
│ (accent)  │ (accent の地に暗い塗りの波形)  │
│ wordmark  │                              │
│ 主題の数字 ├──────────────────────────────┤
│ 目盛り    │ 下の列（帯域・ボイスなど）     │
│ マクロ    │ （暗い地、罫線で区切る）       │
│ NXE       │                              │
└───────────┴──────────────────────────────┘
```

- **サイドバーと主図は 1 つの L 字の反転面**として地続きにする
- v0 のステータスバー（ポインタが乗っているものの説明）は H4 の案に描いていない。
  残すか、どこに置くか、反転面にするかは `V2-9` で決める。反転面にするなら、
  L 字と合わせて 2 つで上限になる
- サイドバーは上から順に: ワードマーク、主題の数字（窓で一番大きい字、
  1 つだけ）、その数字の目盛り、マクロの 2 列、`NXE` の印
- **主図の面は共通、描くものはプラグインごと**。面はアクセントの地で、その上の
  図は**暗い塗り＋白い線**で描く（B 案の差し色）。Sparkleur ならスペクトルの波形、
  Diorama なら `REQ-DIO-013` の距離の図（直接音と反射）、というように、各
  プラグインの UI 仕様が要求する図を入れる。線はゆっくり明滅してよい（点滅は不可）
- 主図の縦の区切り線は、下の列の境界にそろえる
- **下の列もプラグインごと**。帯域を持つもの（Sparkleur など）は v0 の帯域列
  （眉 → バー → 読み値 → SOLO）を引き継ぐ。Doubler はボイスを並べ、UI 仕様が
  外しているボイスの SOLO は置かない。何を並べるかは各プラグインの
  `specifications/ui.md` が正

寸法・余白・書体の段は `V2-9`（Sparkleur 2）で確定し、ここに書き戻す。
**数字は実機で決まる**（`ui.md` の「Dimensions are only settled in a host」）。

## 書体

Mix 系は **Inter（Regular / Medium）+ letter-spacing**、数字は **Geist Mono**。
Host Grotesk（G 案で試した）と allo は候補として残す。替えるなら、プラグインの
バイナリに埋め込めるライセンスかを先に確かめる。
