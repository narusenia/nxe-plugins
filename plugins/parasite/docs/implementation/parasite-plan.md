# Parasite 計画 — Design の最初のフラッグシップ

> 2026-11-25 に計画。ラインナップと順番の理由は
> [`series-plan.md`](../../../../docs/implementation/series-plan.md) の「順番」3。
> 元の案は [`concepts/series-ideas.md`](../../../../concepts/series-ideas.md) の
> Parasite（寄生発振器で原音を変調する。後掛けの FM に近い使い方）。

## 決めたこと

1. **入力（宿主）のピッチに追従する発振器が、宿主に取り付いて変える。**
   新しく作るのはピッチ追従だけで、これが Harmonic エンジンの最初の部品になる
2. **ピッチ追従は YIN**（`parasite-core::pitch`）。約 12 kHz に間引いてから、
   約 5 ms ごとに解析する。50 Hz〜1 kHz。Parasite を知らないように書いて
   あり、2 本目の呼び手（Dew の Follow）が来たので `nxe_audio::pitch` に
   中身を変えずに移した（`resonance-kit-plan.md` の決定 6）
3. **Species は 4 種**（2026-11-25、ユーザーの選択）。`I` は Infection
   - FM — 宿主の位相を寄生音で押す（遅延線を寄生音で揺らす）。押す量は宿主の
     周期に比例させるので、ピッチが変わっても変調指数は同じ
   - Ring — 宿主に `1 − I + I·p` を掛ける
   - Sync — 宿主の周期ごとに戻る寄生音を掛ける。`I` で速さも上がる
     （掃くような音）。戻る瞬間は宿主の周期の窓で 0 にしてあり、段差が出ない
   - Voice — 寄生音が宿主の音量で一緒に鳴る
4. **Hunger は「食べる」**: 出力を、宿主を変えた音から寄生音そのものへ移す。
   **伸ばした音の間に育つ**（約 0.25 秒で満ちる）。アタックでは育たない
5. **Resistance は宿主の抵抗**: アタックで Infection と Hunger が引く。
   アタックは短い平均と長い平均の比で取り、持続音の揺れは無視する幅を持つ
6. **ピッチが取れない音（ドラム、息）では、最後のピッチを保って薄れる**
   （2026-11-25、ユーザーの選択）。約 0.3 秒で消える。Sensitivity は、
   どこまで濁った音をピッチとして信じるか
7. **Spread** は寄生音の横の 2 声（最大 ±2 オクターブ）、**Mutation** は各声が
   比率からゆっくり（約 0.7 Hz）外れる量（最大 ±7 半音）
8. **全部の Species が同じ固定の遅延（FM の最大の押し幅、48 kHz で約 10 ms）を
   通る**。切り替えで音が跳ねず、ドライも揃う。ホストにレイテンシとして報告する
9. **窓は Design 7（製図）の型をここで作る**（2026-11-25、ユーザーの選択）。
   `nxe_egui::design`: 880 × 430。左に正方形の図、右に Host / Parasite / Output の
   3 列の細いスライダー、下に「何が何を動かしているか」の表。キャンバスの
   Design 7 の見本どおり。Singularity と Topology が同じ枠を使う
   - 図は宿主（灰）と出力（アクセント）を、宿主の周期の頭から 2 周期分重ねる。
     伸ばした音では止まって見え、2 本の線の差が寄生の効き。下からの淡い塗りが
     Hunger の今の量
   - 表は見本の変調表（LFO やサイドチェイン）の代わりに、**今寄生音を動かして
     いるもの**を出す（宿主のピッチ、明瞭さ、伸ばした音、アタック）。
     変調表は持たない
   - スライダーとプリセットの結び付けは `kit-ui` を借りる（Singularity が来たら
     共通の場所へ）
10. 色は Design Kit と同じアシッドグリーン（`Palette::DESIGN_KIT`）
11. **窓の文字は全部 Ioskeley Mono NL、ワードマークだけ Inter**（製図の字として。2026-11-25、ユーザーの依頼。
    Geist Mono、Space Grotesk を経てこれにした。`font::drafting`）。枠の箱は描かず、
    罫線と、見出しの下の短いアクセントの棒で区切る。図は 8 × 8 の方眼の上に
    描き、左上に追っている音名、右上に Hunger の量を大きく出す。頭の帯と下の表は差し色の地に暗い字で書く（`Palette::inverted`）。
    頭の `NXE` は文字でなく描いたマーク（`logo::mark`）。プリセットバーと
    Species は名前でなく波形の小さな絵で選ぶ（`design::glyphs`。名前を並べると
    詰まりすぎた）。選んでいる名前は列の見出しの右に出し、絵の名前はカーソルを
    重ねると出る。プリセットバーは共通の部品なので Inter のまま
