## 設計方針

**主役は「声がどこに居るか」** — `REQ-DIO-013` がそう書いている。距離は 1 本の
軸で、そこに直接音と反射音の比が乗る。

**タブを持たない。** パラメータは 8 個で、`.agents/rules/ui.md` の言うとおり
数が決めるのではない — **`DEPTH` と `ROOM` と `WIDTH` は一緒に問われる**ので、
半分のパネルには置けない。Air と同じ 1 画面。

**Advanced の偏差はまだ無い**（`REQ-DIO-009`）。理由は 2 つあって、どちらも
「窓の問題ではない」: 偏差はパラメータを 7 個増やすのでエンジン側の変更であり、
**各偏差が数として何をするかを `dsp.md` がまだ書いていない**。窓を作り直す
必要は無く、下段に 1 行増えるだけ。**それ用の単位を立てるのが正しい**。

**幅は `theme::WINDOW_WIDTH`。** 5 本で 1 つの定数を共有していて、**並べたときに 1 つの製品に見える**ため
（`.agents/rules/ui.md`）。

**高さは算術**。上から順に足す:


**図の高さは 4 本と同じ 200。** 別々に詰めた図は、それぞれ単体では正しくて
**並べると揃わない**（`.agents/rules/ui.md`）。

## 到着の図（`nxe_ui::taps::TapField`）

**1 本の軸が時間であり距離でもある。** 直接音は左端に立ち、反射はそれぞれが
届く時刻に立つ。**遠ざけると絵の重心が右へ動く** — 耳がやっているのと同じ
動作なので、図は機構の可視化ではなく機構そのものになる。

| 何が動くと | 図がどうなる |
|---|---|
| `DEPTH` を上げる | 直接音の茎が縮み、反射の重心が**右へ**動く |
| `ROOM` を上げる | 反射の茎が全部伸びる（時刻は動かない） |
| `DAMPING` | **図では動かない。** 読み値（`HF`）に出る |
| `WIDTH` | **図では動かない。** 読み値（`CORR`）に出る |

**茎の時刻は動かない。** これは実装の帰結で、`DEPTH` が動かすのはタップ列に
掛かる重み包絡だけ（`dsp.md`）。**図が嘘をつかないのは、絵が実際の重みから
描かれているから。**

### なぜスペクトラムではないか

スペクトラムが正しいのは、プラグインの主題が「周波数のどこで何が起きるか」の
とき（Velour の帯域、Air の層）。**距離はスペクトルの量ではない** —
「遠い」と言っているのは直接音と反射の比と到着時刻の広がりで、どちらも
スペクトラムには写らない。

### 描かないもの

- **減衰カーブもテイルも描かない。** プラグインがどちらも持っていない
  （`REQ-DIO-020`）ので、包絡を描くとそれを約束してしまう
- **周波数の情報を描かない。** `DAMPING` は読み値。**軸が 1 本しか無い図に
  2 つ目の量を入れると読めなくなる**
- **`WIDTH` を左右に描かない。** 反射の相関は読み値に出る。図の横軸は時間で、
  それを 2 つの意味に使うことはしない

## 読み値の帯（`nxe_ui::readout`）

7 セル。**固定幅・右寄せ・符号は常に出す**（`.agents/rules/ui.md`）。

| セル | 何 | 出どころ |
|---|---|---|
| `IN` | 入力レベル | `nxe_dsp::Level` |
| `OUT` | 出力レベル | 同 |
| `DIRECT` | 直接音のレベル | 直接音バスの `Level` |
| `ROOM` | 反射音のレベル | 反射バスの `Level` |
| `CLARITY` | **戻している量** | `Engine::clarity_lift_db` |
| `CORR` | 反射音の相関 | `nxe_dsp::Correlation` |
| `HF` | 直接音の減衰コーナー | `Engine::damping_corners_hz` |

**`DIRECT` と `ROOM` が並んでいるのが距離そのもの**（`REQ-DIO-018`）。
比を計算して 1 個の数にはしない — 2 つ並んでいれば比は読めるし、どちらが
動いたかも分かる。

**`CLARITY` は隠さない**（`REQ-DIO-006`）。0.0 のときも `+0.0` と出す —
**符号が出たり消えたりする図はプラグインが自信なさげに見える**
（`.agents/rules/ui.md`）。

**`HF` は無音のとき dash。** `DAMPING` = 0 では減衰が無く、`20000 Hz` と
書くのは嘘（実装は `Coefficients::PASS`）。

## メーター（`nxe_ui::meter`）

IN L / IN R / OUT L / OUT R の 4 本、右の列に縦。Air と同じ形。

## メインの 7 本

`DEPTH` / `DIRECT` / `ROOM` / `DAMPING` / `WIDTH` / `CLARITY` / `MIX`。
**全部同じ大きさ。** Sparkleur は「音を作る 5 つ」と「どれだけ届くかの 2 つ」で
分けたが、ここでは **`MIX` も距離の一部**（wet が原音を置き換えるので、
`MIX` は「どれだけ遠ざけるか」に近い）。

`OUTPUT` は下段に 1 行。**距離の一部ではない**（`REQ-DIO-008` が `DEPTH` を
正規化しているので、これはゲインステージングのためだけにある）。
