# Vocal Depth — 実装計画

> 最終更新: 2026-08-27

要件は [`../requirements/REQ-VDP.md`](../requirements/REQ-VDP.md)。
**DSP 仕様と UI 仕様は未作成** — `VDP-1` に着手する前に `dsp.md` を書く
（式・係数・時定数・耳で詰める定数の一覧）。

**単位ごとに「完了条件」を満たしてからコミットする。** 完了条件は「動いた」
ではなく**測れること**で書く。

## 順序の考え方

```text
VDP-1  初期反射              ← v1 で唯一の新規 DSP。core もここで作る
VDP-2  直接音
VDP-3  DEPTH とラウドネス正規化 ← ゲート。ここが通らないと製品の主張が立たない
VDP-4  ラッパとパラメータ      ← ここで音が出る
VDP-5  DAMPING
VDP-6  距離依存のステレオ幅
VDP-7  CLARITY
VDP-8  詰め（レート・ブロック・極端値）
VDP-9  UI マクロ層と Advanced
VDP-10 UI の図
VDP-11 読み値・メーター・解析の配線
VDP-12 CPU 予算
VDP-13 既定値と耳
```

**ゲートが 1 番目ではない**（Air / Velour / Sparkleur とここが違う）。
`REQ-VDP-008`「`DEPTH` を動かしてもラウドネスが変わらない」は**連動する項が
全部揃って初めて測れる**ので、材料を 2 つ作ってから 3 番目に置く。
**それでもゲートであることは変わらない** — 崩れたら `DEPTH` を 1 本のマクロに
した意味が消え、パラメータの意味づけごとやり直しになる。

**`VDP-4`（ラッパ）が `VDP-5`〜`VDP-7` より前。** Velour の `VEL-5`、Air の
`AIR-4` と同じ判断。`DAMPING` の「布を被せた音にならない」も `CLARITY` の
「戻しすぎない」も**効いたかの判断が耳寄り**なので、音が出る状態を先に作る。

**共有クレートの新規単位が無い。** `REQ-VDP-015` が要求する既存ブロックは
全部 `nxe-audio` にある。唯一の新規は初期反射で、それは `vocal-depth-core` に
置く（`nxe-audio` に上げるのは 2 個目の客 = Vocal Glue が要求したとき）。

## Air から増えている道具

`AIR-*` で共有側に足したもの。**同じものを書き直さない。**

| | 何 |
|---|---|
| `nxe_audio::envelope::Power` | 二乗 → 非対称 1 次のパワーフォロワ。時定数は呼び出し側 |
| `nxe_audio::envelope::coefficient` | 秒 → 1 次係数。3 箇所に同じ式があったのをまとめた |
| `nxe_audio::guard::retune` / `set_thresholds` | 帯としきい値を**状態を保ったまま**動かす。作り直すと参照フォロワが空になり、相対検出器は空の参照に対して無限に harsh に見える |
| `nxe_ui::dots::DotField` | **Vocal Depth では使えない見込み。** 「足した層」を描く図で、こちらは原音そのものが処理を通る（`REQ-VDP-001`）。図は `VDP-10` で別に決める |

### VDP-1 — 初期反射

`reflections.rs`。**`vocal-depth-core` クレートもここで作る**
（`VEL-1` / `SPK-2` / `AIR-1` と同じ位置）。

タップ付き遅延 + 拡散のオールパス数段。**畳み込みも IR も使わない** —
距離で連続的に変化させる必要があり、IR は補間できない（`REQ-VDP-003`）。

- **完了条件**:
  - [ ] `ROOM` = 0 で反射が**ちょうど**無音
  - [ ] 反射の遅延が **10〜120 ms** に収まる（テイルが伸びていない）
  - [ ] `DEPTH` を連続的に動かしてもクリックが出ない（**測定が失敗できることも
        同じテストで確かめる** — `VEL-10`）
  - [ ] 無音を入れて **3 秒以内に完全に無音**（1 次の裾を切る、`SPK-16`）
  - [ ] 44.1 / 48 / 96 / 192 kHz で遅延が**秒で**一致する
  - [ ] `vocal-depth-core` の外から使える形（Glue が借りる）
  - [ ] hostile な値で非有限を出さない
- **要件**: REQ-VDP-003, REQ-VDP-015, REQ-VDP-017
- **依存**: なし
- **決めること**: タップの本数と時刻。**オールパスの段数と係数。**
  タップ時刻を `DEPTH` で動かすのか、量だけ動かすのか
- **見込んでいる罠**: **遅延線の長さはサンプル数、時刻は秒。** 192 kHz で
  120 ms は 23 040 サンプルで、44.1 kHz の 5 292 の 4 倍以上。**確保は
  `initialize` で最大レートぶん**（`.agents/rules/rust.md`）
- **見込んでいる罠**: **タップ時刻を動かすと補間が要る。** 整数サンプルで
  跳ばすとクリックになる。線形補間で足りるか、遅延を動かさず量だけで
  距離を作るかを `dsp.md` で決める
- **見込んでいる罠**: **オールパスの尾はデノーマルへ落ちる。** ホストの中では
  nih-plug が FTZ を立てるので実害は無いが（`SPK-17`）、**テストはホストの
  外で走る**ので「3 秒で無音」は自分で床を切らないと通らない

### VDP-2 — 直接音

`direct.rs`。Presence の動的シェルフ（2〜5 kHz）と Transient の検出。

- **完了条件**:
  - [ ] `DIRECT` を動かすと 2〜5 kHz と Transient が**同時に**動く
  - [ ] Transient の鈍化が子音を潰しきらない
  - [ ] 検出器が入力ゲインに依らない（±12 dB で 0.2 dB 以内）
  - [ ] 新しい検出器を作っていない（`nxe_audio::envelope::Power` の値違い）
- **要件**: REQ-VDP-004
- **依存**: なし
- **見込んでいる罠**: **フォロワは両方対称にして、リリースは比の後ろに置く**
  （`SPK-6`）。非対称なフォロワを比の分子に置くと**定常音でも 3 dB 出る**
- **見込んでいる罠**: **相対検出器は立ち上がるまで無限に反応する**
  （`SPK-18`）。**100〜250 ms 捨ててから測る**

---

### VDP-3 — DEPTH とラウドネス正規化（ゲート）

`depth.rs` / `engine.rs`。連動マクロと、**距離とラウドネスの分離**。

- **完了条件**:
  - [ ] `DEPTH` 全域で出力の RMS が **±0.5 dB 以内**（ピンクノイズと歌の両方）
  - [ ] 同じことが `MIX` の各点で成り立つ
  - [ ] `ROOM` を動かしてもラウドネスが動かない
  - [ ] 正規化が**信号に依存していない**（同じ設定なら素材によらず同じ係数）
- **要件**: REQ-VDP-002, REQ-VDP-008
- **依存**: VDP-1, VDP-2
- **決めること**: **これが一番難しい。** 連動する各項（Presence の削り、
  高域の損失、反射の量、幅）が総エネルギーに与える寄与を打ち消す係数を、
  **パラメータが変わったときに計算する**。`nxe_audio::shaper` の `g` と同じ
  考え方で、**プローブ信号に対する RMS を積分して割る**のが素直な出発点
- **見込んでいる罠**: **信号依存の正規化にしない**（`REQ-VDP-008`）。
  素材ごとに `DEPTH` の効きが変わるほうが問題として大きい。`shaper` が
  同じ判断をしている
- **見込んでいる罠**: **ピンクノイズで測る。** ホワイトは「普通の素材」の
  代理ではない — 帯域幅の都合だけで上が持ち上がる
  （`nxe_audio::harmonics::pink`）

---

### VDP-4 — ラッパとパラメータ（ここで音が出る）

`vocal-depth` クレート。パラメータ宣言、`process()`、`MIX`。**UI はまだ持たず、
ホストの既定パラメータ UI で音を確認する。**

- **完了条件**:
  - [ ] `MIX` = 0 で出力が入力と**ビット一致**（原音は最初に分岐する、
        `REQ-VDP-001`）
  - [ ] 2→2 と 1→2 の両方のレイアウトで動く
  - [ ] 4 ホストで CLAP と VST3 が読み込まれる
  - [ ] `mise run bundle vocal-depth` / `install vocal-depth` が通る
  - [ ] `CLAP_ID` は `com.nxe.vocaldepth`。**出荷後に変えられない**
- **要件**: REQ-VDP-001, REQ-VDP-011, REQ-VDP-012, REQ-VDP-014
- **依存**: VDP-3
- **決めること**: **報告するレイテンシ。** Air と違い**遅延線がある** —
  初期反射は原音より遅れて来るものなので 0 で正しいはずだが、
  `REQ-VDP-012` を読んで確定する
- **見込んでいる罠**: **作ったばかりの `FloatParam` のスムーザは 0 から
  始まる**（`AIR-13`）。ホストは `initialize` で起こすが、テストがやらないと
  **全マクロが下限のプラグイン**を測ることになる。Air は層が −200 dB と出て
  「既定値は何も足していない」という harness だけの結論を一度出した。
  `defaults.rs` の `primed()` をそのまま持ってくる

---

### VDP-5 — DAMPING

`damping.rs`。**直接音と反射音で違う量**、Transient のときだけ高域を保つ。

- **完了条件**:
  - [ ] `DAMPING` が直接音と反射音に**違う量**で掛かる
  - [ ] Transient の瞬間に高域が保たれる（測って固定する）
  - [ ] `DAMPING` 全開でも子音が判別できる
  - [ ] `DAMPING` を動かしてもラウドネスが動かない（`VDP-3` の正規化に乗る）
- **要件**: REQ-VDP-005
- **依存**: VDP-4

---

### VDP-6 — 距離依存のステレオ幅

`REQ-VDP-007`。遠いほど反射の幅が広がり、直接音は中央に残る。

- **完了条件**:
  - [ ] `DEPTH` を上げると生成側の相関が下がる（`nxe_dsp::Correlation`）
  - [ ] 原音の定位が動かない
  - [ ] **モノ和で櫛形が出ない**（Air の `AIR-1` と同じ測り方。1/3 オクターブ
        帯の比のばらつきで見る、**対照実験は遅延ではなくオールパス**）
- **要件**: REQ-VDP-007, REQ-VDP-011
- **依存**: VDP-4
- **見込んでいる罠**: **こちらは位相を回す**（反射は遅延そのもの）ので、
  Air の「構造的に破れない」は使えない。**谷の深さを測って許容量を決める**

---

### VDP-7 — CLARITY

`REQ-VDP-006`。落ちすぎた明瞭度を戻す機構と、**働いた量の公開**。

- **完了条件**:
  - [ ] `DEPTH` を上げても子音の判別が保たれる
  - [ ] 戻した量が取り出せる（UI が使う）
  - [ ] `CLARITY` = 0 で機構が**ちょうど無効**
  - [ ] 普通の素材で戻し量が 0（`SPK-18` の再発防止）
- **要件**: REQ-VDP-006, REQ-VDP-018
- **依存**: VDP-5

---

### VDP-8 — 詰め

- **完了条件**:
  - [ ] ブロックサイズ 1 / 64 / 512 / 4096 の出力が一致
  - [ ] 44.1 / 48 / 96 / 192 kHz で係数が発散しない
  - [ ] 全パラメータの極端値で非有限値を出さず panic しない
  - [ ] 非有限のサンプル 1 個で検出器も遅延線もラッチしない
  - [ ] 音声スレッドの経路に確保が無い（数えるアロケータ）
  - [ ] パラメータの段変化でクリックが出ない（**2 階差分を段の周りと他で
        比べる** — 絶対値の跳びでは測れない、`AIR-7`）
- **要件**: REQ-VDP-016, REQ-VDP-017
- **依存**: VDP-7

---

### VDP-9 — UI マクロ層と Advanced

**着手前に `ui.md` を書く。** メインの 7 本 + `OUTPUT`、Advanced の偏差。

- **完了条件**:
  - [ ] 全パラメータにコントロールがある（`#[id]` を走査するテスト）
  - [ ] **固定幅の合計が窓に収まる**（`AIR-13` で実機がはみ出した。
        テストにする）
  - [ ] `.class("root")` が根に付いている
  - [ ] 窓の高さが部品から計算されている（幅は 720 で 4 本と揃える）
- **要件**: REQ-VDP-009, REQ-VDP-013
- **依存**: VDP-8
- **見込んでいる罠**: **`Auto` 幅の親の中で `Stretch` は 0 に潰れる。**
  Air の `OUTPUT` がこれでノブとラベルと数値を同じ原点から描いた

### VDP-10 — UI の図

- **決めること**: **何を描くか。** Air の `DotField` は「足した層」の図で、
  こちらは原音が処理を通るので前提が違う。距離そのもの（直接音と反射の比、
  遅延の分布）を描くのか、スペクトラムに落とすのか
- **要件**: REQ-VDP-013, REQ-VDP-018
- **依存**: VDP-9
- **決まっていること**: 新規ウィジェットを作るなら**同じ変更で
  `examples/gallery.rs` に入れる**（規約）

### VDP-11 — 読み値・メーター・解析の配線

- **完了条件**:
  - [ ] `CLARITY` の戻し量が出る（`REQ-VDP-006` が求めている）
  - [ ] 音が止まると表示が減衰して消える（3 秒以内に完全に 0）
  - [ ] 解析を止めても音が変わらない（表示専用）
  - [ ] **`analysis.rs` の `Handoff` が全部 `lib.rs` で書かれている**

        **テスト全通のまま窓が静止した**）
- **要件**: REQ-VDP-018
- **依存**: VDP-10

- **完了条件**:

  - [ ] 既定値で「声が一歩下がった」が成立する
  - [ ] 挿して `DEPTH` を 1 本回すだけで判断できる
- **要件**: REQ-VDP-021

## 見込んでいる罠（今日までに払った授業料）

`docs/HANDOVER.md` に全部あるが、Vocal Depth で特に効きそうなもの:

- **整形済みファイルへの文字列置換は黙って失敗する。** `AIR-*` で 6 回。
  **置換のあとは grep する**（`.agents/rules/rust.md`）
- **測定の側が間違っていることのほうが多い。** Air で落ちたテストの大半は
  実装ではなく測り方だった — 広い帯域通過はレートで歪む、蓋の上を測る
  フィルタは自分の裾を測る、櫛形の対照実験に遅延を使うと通ってしまう
- **しきい値は分布から置く**（`SPK-18`）。p50 / p95 / max を並べてから。
  **末尾の 1 サンプルの引き量で決めない**
- **「普通の素材で動かない」は 2 音のテストでは守れない。** 広帯域で測る
- **測定が失敗できることを同じテストの中で確かめる**（`VEL-10`）
