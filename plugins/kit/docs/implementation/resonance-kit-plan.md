# Resonance Kit 計画 — Dew、Halo

> 2026-11-25 に計画。ラインナップと順番の理由は
> [`series-plan.md`](../../../../docs/implementation/series-plan.md) の「順番」4。
> ここは単位と、出荷後に変えられないものを持つ。
> 2 本とも Colour の Kit で、Dew は Meniscus から、Halo は Prisma から切り出す。
> 元の案は [`concepts/series-ideas.md`](../../../../concepts/series-ideas.md) の
> 小型プラグイン案（Dew「水滴状の倍音トランジェント付加」、Halo「原音の周囲に
> 調性的残響を生成」）。

## 決めたこと

1. **1 本ずつ別のプラグイン**、最後のつまみは足す量。表示名はほかの Kit の
   `Mix` ではなく **`Wet`**（フィールドは `mix` のまま）。乾いた音を減らさず足す
   だけなので、Mix と呼ぶと乾いた音と混ぜる割合に読める（2026-11-25、ユーザーの
   選択）。Dew はつまみ 4 つ、Halo は 5 つ（どちらも反応が鈍いという耳の結果で
   Sensitivity を足した）
   - 窓の下の行は数字の箱と区切りボタンをやめ、ラベル付きの `number`
     （`Root 220 Hz`）、`toggle`（`Tuning [Free]`）、`select`
     （`Chord ⌜Fifth ▾⌟`）にした（2026-11-25、ユーザーの選択）。3 つとも
     `nxe-egui` にあり、ほかのプラグインでも使える
2. **DSP は `resonance-core` に置く。** Meniscus と Prisma が来たらそこから
   使う。プラグインのクレートは宣言と窓だけを持つ
3. **差し色は Colour の色 `Palette::COLOUR_KIT`（アクア `#5CE1E6`）**
   （2026-11-25、ユーザーの選択）。左の縦帯は `COLOUR KIT`。窓は Kit の型
4. **リリースは `[kit]` シリーズに入れる。** Design の Kit と同じシリーズで、
   色で見分ける
5. **Dew の中身**:
   - 入力のアタック（2 ms と 60 ms の電力の平均の比が、`Sensitivity` で決まる
     12 dB〜1.5 dB を越えたとき。次のアタックまで 50 ms 空ける）ごとに、
     **水滴**を 1〜6 滴落とす。水滴は減衰する正弦で、音程は少し下（落ち着く先の
     1/1.6）から上に滑って落ち着く。泡が閉じるときの鳴り方
   - **滴の大きさは、鳴り始めたときの入力の直近のピーク（300 ms で戻る）で
     決める。** 最初の滴も 5 ms 待つので、ゆっくり立ち上がる音でも小さくならない
     （最初の版はアタックを見つけた瞬間の大きさで決めていて、約 25 dB 小さく
     聞こえなかった）
   - `Pitch`（200 Hz〜8 kHz）は滴が落ち着く音程。窓では Free / Follow の横の
     数字の箱（`nxe_egui::number`。つまみと同じく、ドラッグで変え、ダブルクリックで
     既定値、Cmd+クリックで打ち込み）。`Size`（0〜100 %）は滴の大きさで、
     大きいほど長く鳴り（減衰の時定数 25〜150 ms）、ゆっくり滑る
   - `Splash`（0〜100 %）は 1 回のアタックで落ちる滴の数（1〜6）、時間の散らばり
     （最大 60 ms）、左右の広がり、音程のばらつき（±1〜6 半音）
   - `Wet`（フィールド `mix`）は**足す量**。乾いた音はいつもそのまま通り、0 % で入力と
     ビット一致になる。遅らせないのでレイテンシはない
   - **`Tuning` で音程の決め方を切り替える**（2026-11-25、ユーザーの選択）。
     `Free` は Pitch の音程、`Follow` は入力のピッチの**オクターブと 5 度**
     （1・2・3・4・6・8・12… 倍）のうち、Pitch に一番近いものに落ち着く。
     **鳴っている間も合わせ続ける**ので、新しい音の頭で落ちた滴も、追従が新しい
     音をつかむと（数十 ms）そちらへ滑る。ピッチが取れない（明瞭さ 0.85 未満）
     ときは Free と同じ。最初の版は全部の整数倍音から選び、アタックの瞬間に
     決めていたので、2 kHz では 9・10 倍音になって音と関係が聞こえず、音が
     変わると 1 つ前の音に合っていた（2026-11-25、耳の結果）
   - 乱数は決定的なので、同じ入力なら同じ水滴が落ちる
   - 図は、鳴っている滴を**波紋**で描く。横は左右の位置、縦は音程（100 Hz〜
     8 kHz）、時間とともに広がり、減衰とともに消える
6. **Halo の中身**:
   - 和音の各音に共鳴器を 1 つずつ置き、入力で鳴らす。共鳴器は複素数の 1 極
     （`y = r·e^{iω}·y + g·x`）。音程が動いても係数を作り直すクリックが出ない
   - 最初は `g = 1 − r`（自分の音程でちょうど利得 1）にしたが、帯域が 1 Hz も
     なく、数セント外れた声が約 50 dB 下にしか返らず「全然反応しない」と
     言われた（2026-11-25）。いまは `g` を音程の数 % の幅で利得 1 になるように
     取り、ちょうど合った音が鳴りすぎないよう、共鳴器ごとの振れ幅を入力の
     直近のピーク（共鳴器と同じ速さで下がる）の何倍かで抑える。複素数の大きさ
     で抑えるので、純音は純音のまま
   - **音程は Free / Follow を切り替える**（2026-11-25、ユーザーの選択）。Free は
     `Root`（40 Hz〜1 kHz、窓では `number`）、Follow は入力のピッチ（取れない
     ときは最後の音程を保つ）。根音は 40 ms で滑る
   - **和音は `Chord` で選ぶ**: `Fifth`（1、3/2、2、3、4 倍。3 度なし、既定）、
     `Maj`（5/4 を足す）、`Min`（6/5 を足す）。2 オクターブ、純正律
     （2026-11-25、ユーザーの選択は「和音」。3 度の長短を決めるために種類を
     選べるようにした）
   - つまみは `Sensitivity`（和音からどれだけ外れた音まで鳴らすか（音程の
     1〜8 %）と、響きの上限（入力の 1〜4 倍）。50 % で約半音の半分、2 倍）、`Decay`（T60 0.3〜8 s）、`Shimmer`（各音を最大 ±18 セント、
     0.15〜0.6 Hz でゆっくり揺らす。音ごとに速さが違う）、`Tone`（上の音の重み
     `ratio^−tilt`、tilt 1.6〜0）、`Wet`（足す量。0 % で入力とビット一致）
     （2026-11-25、ユーザーの選択）
   - 響きは `tanh` で 1.5 を上限にやわらかく抑える
   - 図は和音を**同心円**で描く。内側が根音、外側が 2 オクターブ上。輪の線は
     選んだ和音から描くので鳴る前から見え、光り方は鳴っている強さ。真ん中に
     根音の名前
7. **ピッチ追従は `nxe-audio::pitch` に移した。** Parasite の YIN を、2 本目の
   呼び手（Dew の Follow）が来たので中身を変えずに移した（`architecture.md` の
   規則）

| | Dew | Halo |
|---|---|---|
| 名前（`truce.toml`） | `Dew` | `Halo` |

| ID | 単位 | 依存 | 状態 |
