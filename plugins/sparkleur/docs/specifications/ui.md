## 設計方針

**ゲインが見える。** マルチバンドダイナミクスで一番読みたいのは「いま各帯域が
どれだけ上下しているか」。**unity の線を引いて、実際に掛かっているゲインが
そこから上下に動く**のが画面の主役。上げコンプは線より上に伸びる。

**約束が見える。** 「明るくなるのに痛くならない」を守っているのは De-Harsh で、
普通のプラグインでは働いた瞬間に画面上で何も起きない。**働いたら区画が沈む**
（Velour と同じ手）。

**普段触るのは 7 つのノブだけ。** パラメータは 33 個あるが、常用するのは
`SPARK` / `CHARACTER` / `BODY` / `AIR` / `SPEED` / `MIX` / `OUTPUT`。
残りは Advanced タブ。

**同じ音量で A/B できる。** IN と OUT を常時並べる（Velour と同じ理由）。

```text
│   │        ╷    ╷      ╷      ╷      │  │   ╱   │  │  ▓   │
│   │  ▁▁▁  ▔▔▔  ▁▁▁▁  ▔▔▔▔▔  ▔▔▔▔     │  │  ╱    │  │      │
│   │ ──────────────── unity ───────────│  │ ╱     │  │ OUT  │
│   │  SUB  BODY  MID  PRES   AIR       │  │伝達曲線│  │  ▓   │
│   └──────────────────────────────────┘  └───────┘  │  ▓   │
│    20   100   500   2k   5k   20k        PRESENCE  │      │
│                                                    │      │
│  ┌──────────────────────────────────────────────┐  │      │
│  │ [ MAIN ] [ ADVANCED ]                        │  │      │
│  │                                              │  │      │
│  │  SPARK  CHARACTER  BODY  AIR  SPEED          │  │      │
│  │   ◯       ◯       ◯    ◯    ◯           │  │      │
│  │              MIX   OUTPUT                    │  │      │
│  └──────────────────────────────────────────────┘  │      │
└────────────────────────────────────────────────────┴──────┘
```

寸法は **680 × 468**（`SPK-15` で実機を見て確定）。Velour の 680 × 528 から
始めて図の高さを 236 → 176 に詰めた — **こちらは区画が中央の線に集まる設計**
なので、区画が床から生える Velour と同じ高さでは黒ばかりになる。
Velour が 580 → 528 でやったのと同じこと。

**伝達曲線のプロットは 140 × 140 の正方形。** 対角線が 45° になるのは 2 軸が
同じ長さのときだけで、縦長の箱では「線より下は圧縮」が一目で読めない。

## Band Field（5 区画）

`nxe_ui::band::BandField` をそのまま使う。`Vec<Band>` なので本数は自由。
**意味の対応が Velour と違う。**

| | Velour | Sparkleur |
|---|---|---|
| 区画の高さ | その帯域を**足している量** | その帯域の **`GAIN`**（unity が中央の線） |
| 縦ドラッグ | 帯域の量 | **`GAIN`** |
| `delta`（生きた表示） | Guard の引き（下向きのみ） | **実際に掛かっているゲイン**（上下） |
| レール | `FOCUS` | `FOCUS`（同じ） |

### `nxe-ui` に要る変更

```rust
pub struct Band {
    ...
    pub reduction: f32,   // 0..=1、下げるだけ
       ↓
    pub delta: f32,       // -1..=1、下が圧縮・上が上げコンプ
}
```

**上げコンプが半分の製品で、絵が上げを描けないのは通らない。** Velour は負の
値しか渡さないので挙動は変わらない。規約どおり `examples/gallery.rs` も同じ
変更で更新する（`UI-13` の追加変更）。

### 何が図で読めるか

- **上下コンプの動き** — 線より上に伸びれば持ち上げ、下に沈めば圧縮。
  **これが OTT 系で一番読みたい情報**で、数値では伝わらない
- **`FOCUS`** — 5 区画がまとめてスライドする
- **De-Harsh** — 働いた瞬間に PRESENCE の区画が沈み、`ACCENT` から `MUTED` 側へ
  寄る。沈んだ量がリダクションそのもの
- **Sparkle** — AIR の区画が光った瞬間だけ明るくなる（`snap` 包絡を `tint` に
  乗せる）
- **`SPARK` と `GAIN` の違い** — `SPARK` を上げると区画が**動く量**が増え、
  `GAIN` を上げると区画そのものが上がる。`REQ-SPK-010` の直交が図で確認できる

### 操作

- **区画を縦ドラッグ** — その帯域の `GAIN`
- **下端のレールを横ドラッグ** — `FOCUS`
- `Shift` = 微調整、ダブルクリック = 既定値に戻す
- ドラッグ中はホストへジェスチャー開始／終了を通知する
- ポインタが乗った区画の index を通知（Advanced 表と小窓の連動）

### 描かないもの

- **区画に周波数の数値を書かない。** vizia の `draw_text` は view 自身の
  テキストしか描けないので、目盛りは呼び出し側が `Label` を絶対配置する
- **ダイナミクスの曲線を重ねない。** 軸が違う（周波数 vs レベル）。小窓に分ける

## 伝達曲線の小窓

`BandField` の右。`nxe_ui::curve::CurveView`（曲線 1 本だけ、帯もハンドルも
解析も渡さない）。**Velour と中身が違う** — あちらは波形の伝達曲線、こちらは
**ダイナミクスの伝達曲線（入力 dB → 出力 dB）**。

- 45° の線を基準に引く。**下が圧縮、上が持ち上げ**として読める
- 上下のニーが**両方見える**。`CHARACTER` を回すとニーが 2 つ同時に動く
- 表示するのは **SOLO 中の帯域 → 無ければホバー中 → どちらも無ければ
  PRESENCE**（Velour と同じ順。PRESENCE は痛みの出る場所で、この製品の
  主戦場）
- 下にその帯域の名前を出す
- **読み取り専用。** 曲線を掴めるようにしても書き込む先が 4 つ（上下のしきい値と
  比）に分かれていて、どれが動いたのか分からなくなる
- 範囲は −60〜0 dB。`velour_core` の窓と同じ理由で、**窓を埋める**ように
  スケールする（Velour では固定天井にして「ドライブを上げるほど曲線が小さく
  なる」バグを作った）

## メーター

右の縦帯。**タブで消えない。** Velour と同一（`nxe_ui::meter::Meter` × 4、
IN / OUT × L / R、ピークホールド付き）。

- **リダクションのメーターは持たない。** 区画が上下することで見えている

## タブ

### MAIN

```text
  SPARK   CHARACTER   BODY   AIR   SPEED
    ◯        ◯        ◯     ◯     ◯

                 MIX    OUTPUT
                  ◯       ◯
```

`CHARACTER` の読み値は**軸を 3 等分した区画の名前 + パーセント**
（`POLISH 27 %`）。Velour で 3 つの名前を並べて失敗した（`.accent` が塗りだった /
サイズが変わる / 列幅を食って隣が切れる）ので、**最初から 1 行**にする。

**「一番近いアンカー」ではない**（`SPK-18`）。アンカーは POLISH が 0.0、
GLOSS が 0.5、CRUSH が 1.0 で、**名前の並びどおりには離れていない** — 両端の
2 つが端に、GLOSS が真ん中にいるので、「一番近い」だと**GLOSS が軸の半分を
取り、他の 2 つが 4 分の 1 ずつ**になる。既定の 0.27 が `GLOSS 27 %` と出て
いたのはこれで、`REQ-SPK-006` が「POLISH 寄り」として 0.25〜0.30 を選んだのと
真正面からぶつかった。**3 等分すると境界が 0.33 と 0.67**になり、ノブを見て
「POLISH 寄り」と言える位置がそのまま POLISH になる。

**両端は名前だけ**にする。`POLISH 0 %` は「polish が 0」と読めるが、実際は
**一番 polish が強い**設定。パーセントはパラメータ自身の値なので、
ホストのオートメーション表示と 2 つの違う数字が出ることはない。

| 位置 | 読み値 |
|---|---|
| 0.00 | `POLISH` |
| 0.27（既定） | `POLISH 27 %` |
| 0.50 | `GLOSS 50 %` |
| 0.80 | `CRUSH 80 %` |
| 1.00 | `CRUSH` |

### ADVANCED

```text
          UP      DOWN     GAIN    SOLO        FOCUS      ◯
  SUB    ──●──   ──●──   ──●──    [ ]
  BODY   ──●──   ──●──   ──●──    [ ]        DE-HARSH  ──●──
  MID    ──●──   ──●──   ──●──    [ ]        SUB PROT  ──●──
  PRES   ──●──   ──●──   ──●──    [ ]        SNAP      ──●──
  AIR    ──●──   ──●──   ──●──    [ ]        LIFT      ──●──
                                          OVERSAMPLE [2x][4x]
```

- `UP` / `DOWN` / `GAIN` は `Bar`。`UP` / `DOWN` は**重み**（0 から右へ）、
  `GAIN` は双極（`Bar::bipolar`）
- `SOLO` は **`.segment` を当てた `Label`** に `checked` と `on_press`
  （新しいウィジェットは要らない）
- `DE-HARSH` / `SUB PROT` は**双極の偏差**（0 = `CHARACTER` に従う）
- `LIFT` = 上げコンプの床（`REQ-SPK-003`）。**右に振ると OTT らしい呼吸が出る**
- `FOCUS` は小さい `Knob`（双極）
- **バーには必ず高さを指定する**（`height: 10px`）。Velour で指定を忘れて
  Advanced の表が「動かないコントロール」になった（`.agents/rules/vizia.md`）

行にポインタが乗ったら `BandField` の対応する区画をハイライトする。
`Ui::hovered` 1 つで両方向（Doubler / Velour と同じ）。

## 必要なコンポーネント

### そのまま使える（変更なし）

| コンポーネント | 使うところ |
|---|---|
| `theme` / `font` / `icon` | 全体。`font::title` でワードマーク |
| `input::Gesture` | 全体 |
| `Knob` | メイン 7 個、`FOCUS` |
| `Bar` | Advanced の 15 + 4 個 |
| `SegmentedControl` | タブ、オーバーサンプル |
| `CurveView` | ダイナミクスの伝達曲線（曲線だけ） |
| `Meter` | IN / OUT × L / R |
| `.segment` を当てた `Label` | `SOLO` × 5 |
| `nxe_dsp::{Handoff, Level, Spectrum}` | 解析 |

**`ToggleSwitch`（`UI-9`）は 3 個目のプラグインでも要らなかった。**
計画から落として良い。

### 変更が要るもの

| コンポーネント | 何 | なぜ |
|---|---|---|
| `nxe_ui::band::Band` | `reduction` → **符号付きの `delta`** | 上げコンプが描けない |
| `examples/gallery.rs` | `BandField` のパネルを上下に動かす | 規約（ウィジェットの変更は gallery を要求する） |

### 共通化の期限が来たもの

| | 何 | どこへ |
|---|---|---|
| `param_bind.rs` | Doubler と Velour で**同内容が 2 つ**。3 個目が要求した | **`nxe-ui` ではなく**、nih-plug と vizia の両方を知ってよい新クレート。`nxe-ui` に入れると gallery が nih-plug をリンクして単体起動できなくなる |

`nxe-audio`（DSP の共有、`REQ-SPK-015`）とは別のクレートになる。名前は
`nxe-plug-ui` を仮に置く（`SPK-11` で確定）。
